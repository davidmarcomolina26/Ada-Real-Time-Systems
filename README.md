
# Ada – Real-Time Systems

Academic exercises and laboratory assignments developed in **Ada** as part of the Real-Time Systems course at the University of Alcalá (UAH).

This repository contains practical work covering fundamental programming concepts, data structures, concurrent programming and synchronization mechanisms using the Ada programming language.

## 📚 Contents

The repository is organized into laboratory exercises, practical assignments and additional exercises.

| Section | Topics |
|---|---|
| Lab 1 | Ada programming fundamentals |
| Lab 2 | Arrays, records, procedures and exceptions |
| Lab 3 | Packages, private types and data structures |
| P1 / P2 | Programming exercises and data types |
| Practice 4 | Concurrent sensor simulation |
| Practice 5 | Dining Philosophers problem |
| Practice 6 | Producer-Consumer problem |
| Exam Preparation | Additional exercises and practical exam preparation |

## 🛠️ Technologies and Tools

- **Programming Language:** Ada
- **Compiler:** GNAT
- **Development Environment:** Visual Studio Code
- **Version Control:** Git and GitHub

## 🧠 Concepts and Skills

The exercises cover several topics related to software development and real-time systems:

- Ada syntax and programming fundamentals.
- Procedures, functions and modular programming.
- Arrays, records and data structures.
- Packages and private data types.
- Exception handling.
- Concurrent programming using Ada tasks.
- Task synchronization and communication.
- Protected objects and shared resources.
- Classic concurrency problems.

## ⚙️ Getting Started

### Requirements

To compile and execute the exercises, you need:

- GNAT Ada compiler.
- A compatible development environment (such as Visual Studio Code).

### Compilation

Navigate to the directory containing the Ada source file and compile it using:

```bash
gnatmake filename.adb
```

Replace `filename.adb` with the corresponding source file.

The compiler will generate the executable and other compilation files.
